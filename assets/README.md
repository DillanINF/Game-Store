# Assets Directory

This folder contains media assets for the GameStore project.

## Files

### Screenshots
- **screenshot-0.png** - Homepage/Store view showing game catalog
- **screenshot-1.png** - Game details page
- **screenshot-2.png** - Shopping cart and checkout flow

### Presentation
- **presentation.png** - Project presentation slide/banner

## Usage

These assets are used for:
- Project documentation
- GitHub repository preview
- Presentation materials

## Adding New Assets

When adding new images:
1. Use descriptive file names
2. Optimize images for web (compress when possible)
3. Update this README with new asset descriptions
4. Preferred formats: PNG for screenshots, JPG for photos

## Image Guidelines

- Screenshots should be high quality (1080p or higher)
- Keep file sizes reasonable (< 3MB per image)
- Use consistent naming convention: `screenshot-{number}.png`
